# Армянский словарь для Microsoft Word

Пользовательские словари Word (`.dic`) для восточноармянского языка (hy-AM), собранные из
Hunspell‑словаря [araktransfer](https://sites.google.com/site/araktransfer/home/spell-checkers)
в упаковке [wooorm/dictionaries](https://github.com/wooorm/dictionaries/tree/main/dictionaries/hy).

Word не умеет читать Hunspell‑словари (`.aff` + `.dic`) напрямую: пользовательский словарь Word —
это просто список слов. Поэтому все словоформы развёрнуты заранее (склонения, артикли, притяжательные
окончания, спряжения, частицы `կ-`/`չ-`), а затем проверены самим hunspell: в словарь попадают только
формы, которые hunspell с исходным словарём признаёт правильными.

## Файлы

| Архив | Словоформ | Что внутри |
|---|---|---|
| [`dist/hy-AM-full.zip`](dist/hy-AM-full.zip) | 12 252 105 | все формы, 9 файлов `hy-AM-full-01…09.dic` |
| [`dist/hy-AM-compact.zip`](dist/hy-AM-compact.zip) | 7 269 454 | без форм с приставками `կ-`/`չ-` (կգրեմ, չգրեցի…), 9 файлов |

Словарь разбит на 9 частей, потому что Word позволяет подключить не больше 10 пользовательских
словарей одновременно (десятый — стандартный `CUSTOM.DIC`). Подключать нужно **все 9 файлов**
выбранного варианта. Оба варианта сразу подключить нельзя — выберите один.

Формат файлов: UTF‑16 LE с BOM, переводы строк CRLF — так Word хранит свои словари.

## Установка

**Windows:** Файл → Параметры → Правописание → «Настраиваемые словари…» → «Добавить…» и выберите
файлы `.dic` (удобно предварительно положить их в `%AppData%\Microsoft\UProof`). Для каждого
добавленного словаря укажите «Язык словаря»: «Все языки» (или «Армянский»).

**macOS:** Word → Параметры → Правописание → «Словари…» → «Добавить…».

Текст должен быть размечен языком, для которого Word выполняет проверку (Рецензирование → Язык).
Если для армянского у вас нет средств проверки правописания Office и Word пишет, что проверка
невозможна, пометьте армянский текст другим языком с проверкой: при словаре на «Все языки» слова
из словаря будут считаться правильными, а остальные подчёркиваться.

## Ограничения

- Словарь огромный (сотни мегабайт после распаковки). Современные версии Word не имеют
  документированного лимита на размер пользовательского словаря, но загрузка может быть медленной.
  Если Word тормозит, возьмите компактный вариант.
- Пользовательский словарь даёт только проверку «есть слово / нет слова»; подсказки исправлений
  Word будет брать из своих словарей, а не из Hunspell.
- Ошибки в самих словах — к автору исходного словаря (araktransfer).

## Сборка

Нужны `bash`, `curl`, `python3`, `hunspell`, `zip`:

```bash
./build.sh
```

Скрипт скачивает словарь из закреплённой ревизии wooorm/dictionaries, разворачивает его
(`tools/expand_hunspell.py` — штатный `unmunch` на этом словаре падает), фильтрует через
`hunspell -l` и записывает словари Word (`tools/write_word_dic.py`). Количество частей задаётся
переменной `PARTS` (по умолчанию 9).

В исходном `index.aff` есть ошибка: у суффиксного класса `VD` объявлено 171 правило, а фактически
их 172. Из‑за этого hunspell неверно разбирает файл и отвергает даже простые формы вроде
`կարգադրիչներ`. `build.sh` исправляет счётчик перед сборкой.
